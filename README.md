TripAdvisor Clone

A responsive frontend clone of the TripAdvisor landing page built using **HTML5** and **CSS3**. This project was created as part of my weekly frontend development practice to strengthen my understanding of responsive web design, semantic HTML, Flexbox, and modern CSS layouts.

Features

* Responsive design for desktop, tablet, and mobile devices
* Modern and clean user interface
* Navigation bar with search functionality
* Travel destinations, hotels, restaurants, and attractions sections
* Interactive category navigation
* Well-structured footer
* Built with semantic HTML and responsive CSS

Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Web Design

Learning Outcomes

Through this project, I improved my skills in:

* Structuring web pages using semantic HTML
* Creating responsive layouts with CSS Flexbox
* Designing modern and user-friendly interfaces
* Building pixel-perfect website clones
* Writing clean, organized, and maintainable code
